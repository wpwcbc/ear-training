Hold the harmony. Move at your pace.

Start a sustained chord progression and step through each change manually. Perfect for ear focus, improvisation, and intonation.

Quick guide

  1. Pick or build a progression.
  2. Set key center, loops, and key shift per loop.
  3. Press Start Audio, then Start Drone.
  4. Use Next chord to advance.
