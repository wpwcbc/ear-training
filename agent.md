# Project Working Guidance

## Primary Direction Reference

Read [jazz-ear-lab.md](jazz-ear-lab.md) before proposing, planning or implementing
future changes. The user designated this confirmed project-intent document as
the focus for subsequent work on 2026-10-23.

Use it to judge musical purpose, priorities, measurement boundaries and whether
a proposed change supports Continuous Harmonic Hearing. Accuracy comes before
speed; distinguish objectively scored recognition, self-assessed audiation and
the separate downstream goal of bass execution. Do not overstate progress or
generalization from the available evidence.

This is a product-direction reference, not an implementation specification or
authorization to build every example. Its open decisions remain open. Consult
existing feature specifications and source for implementation details; surface
conflicts with the intent instead of silently changing it. Do not rewrite the
confirmed intent based on assumptions or incidental feature requests.

Do not infer authorization for UI redesign or new exercises from this reference
alone; scope implementation to the user's actual request.

For V2 Release 1, use [V2_RELEASE_1_SPEC.md](V2_RELEASE_1_SPEC.md) as the
implementation contract under the project intent. V2 lives at
`jazz-ear-lab-v2/` with `jazzEarLab:v2:*` data; preserve Legacy M1-M7 and its
records. See [V2_RELEASE_1_IMPLEMENTATION.md](V2_RELEASE_1_IMPLEMENTATION.md)
for timing/default choices, verification and release limits.
