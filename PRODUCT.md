## Legacy Context

Browser-local music ear training with Jazz Ear Lab modes M1-M7 and legacy trainers.
The established workflow is Practice -> configuration -> session -> results -> history.
Insights are scripted and evidence-aware; self-ratings are not measured singing accuracy.
Audio, question generation, scoring and analytics definitions are outside the redesign scope.
Existing local records, presets, routes and preferences must remain compatible.
The requested visual reference is the supplied Donezo-inspired system, not its business features.
No accounts, cloud sync, collaboration, invented metrics or AI summary API are requested.
The primary use is repeated individual practice on desktop and mobile. The initial
reference user is a theory-literate jazz bassist; broader public positioning remains
undecided, as described in the project-intent document.
