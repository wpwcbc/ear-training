# V2 Assets

Source Sans 3 is self-hosted in `fonts/`; see its README and OFL.txt.

Interface glyphs use Lucide SVGs from `../jazz-ear-lab/icons/` under the
existing ISC license at `../jazz-ear-lab/icons/LICENSE`. The local
`square.svg` comes from https://lucide.dev/icons/square with its rectangle
filled using `currentColor` for Stop, under the same license.

Approved generated design boards and screenshot/diff evidence live under
the repository's `.impeccable/` development directory. They are references,
not runtime application images; no comparison board, design contract or
synthetic performance screenshot is embedded in the interface.
