# Source Sans 3

Self-hosted Google Fonts distribution of Adobe Source Sans 3, weights 400,
500, 600 and 700. Licensed under the SIL Open Font License in OFL.txt.

Source CSS: https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400;500;600;700&display=swap
License: https://github.com/google/fonts/blob/main/ofl/sourcesans3/OFL.txt

The approved Signal Route identity calls for a readable humanist sans. The
automatic font matcher could not resolve its browser and returned an unrelated
catalog-only face; Source Sans 3 follows the user-approved humanist direction
rather than treating that fallback ranking as a visual requirement.
